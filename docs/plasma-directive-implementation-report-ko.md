# PLASMA 지침 적용 현황

기준일: 2026-09-19. 이 문서는 화면에 이름만 있는 기능과 실제 데이터가 동작하는 기능을 구분한다.

## 1단계 중요 기능: 부분 완료

- `GOD'S EYE VIEW` 타이틀과 PLASMA 브랜드, Pretendard 로컬 폰트, 네이비/시안 리퀴드 글래스를 적용했다.
- PC용 한국어 로그인·회원가입 화면과 Supabase 연결 코드를 준비했다. 현재 연결된 Supabase 프로젝트가 없어 실제 계정 생성은 아직 비활성이다.
- 음성 명령 상태를 Grok 스타일 아바타의 대기·듣기·생각·말하기 애니메이션으로 연결했다.
- ElevenLabs의 별도 창은 제거했다. 음성 명령 응답 때만 서버 TTS를 호출하고, 실패하거나 오프라인이면 브라우저 한국어 음성으로 대체한다.
- 음성 응답과 같은 한국어 문장을 자막으로 최대 7초 표시한다. 서버 TTS는 IP 기준 하루 50회 방어선을 갖는다.
- 상단의 깨진 아이콘 글자를 Material Symbols 아이콘으로 복구했고 로딩 화면은 PLASMA 앱 아이콘을 사용한다.
- Capacitor, Electron, TestFlight, APK/AAB 패키지는 아직 구축하지 않았다.

## 2단계 버그 및 안정화: 진행 중

- 레이어 단위 예외 격리, 오류 상태 표시, 정적 폴백과 수동 재시도 경로는 존재한다.
- 항공·선박 레이어의 404는 공개 API의 CORS·인증·레이트 제한 문제까지 포함하므로 서버 프록시와 키 구성이 더 필요하다.
- 화면 밖 객체 제거, 모든 누수의 프로파일링 검증, 장시간 모바일 발열 시험은 완료되지 않았다.

## 3단계 성능: 부분 완료

- 렌더 요청 제어, 가시성 정지, 레이어별 로딩 제한과 기존 LOD 경로를 유지한다.
- Rust/Wasm 코어 교체와 전체 마커 GPU 인스턴싱 전환은 아직 구현하지 않았다.
- 따라서 모든 기기에서 60 FPS를 보장하는 단계는 아니다.

## 4단계 UI와 확장 기능: 부분 완료

- 손 추적, 플랜 업그레이드, 스코프 UI를 제거했고 해저 케이블은 메뉴에서 숨겼다.
- 날씨, 안전도, 대피소·병원, 교통, 긴급 차량, 대기오염, 재난, 낙뢰, 오로라, ISS, 해류, 국경, 분쟁, 거리 사진 등을 레이어 탭에 한국어로 분리했다.
- 일부 항목은 실제 피드가 아니라 기능 슬롯 또는 폴백 데이터다. 전체를 실시간 연결한 상태는 아니다.
- 오프라인은 앱 셸과 제한된 캐시 수준이며 전 세계 위성·3D 타일 완전 오프라인은 제공하지 않는다.

## 5단계 배포: 부분 완료

- 현재 웹 버전은 Sites 정적 호스팅으로 배포한다.
- 정적 호스팅에서는 `/api/elevenlabs/tts` 같은 서버 함수가 실행되지 않아 브라우저 한국어 TTS로 자동 대체된다.
- ElevenLabs를 실제로 쓰려면 서버 함수가 가능한 배포 대상과 `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` 환경 변수가 필요하다.
- 10단계 CI 보안 검사, 앱스토어, 플레이스토어, Windows/macOS 패키징은 미완료다.

## 6단계 실데이터 레이어: 혼합 상태

- 기존 항공, 위성, 지진, 라디오 등 일부 모듈은 실데이터 또는 공개 폴백을 사용한다.
- RainViewer, USGS, GDACS, OpenAQ처럼 키 없이 검증 가능한 소스를 우선 복구한다.
- AISStream, TomTom, NASA FIRMS, Google Photorealistic 3D Tiles, CCTV는 약관에 맞는 키와 백엔드 프록시가 있어야 완성된다.
- 경찰차·구급차·군사·실종자·CCTV는 공개 허용 피드 범위에서만 구현하며 개인 추적이나 접근 제한 우회는 하지 않는다.

## 다음 작업 순서

1. 현재 PC 빌드의 404 요청을 네트워크 로그로 전수 분류한다.
2. 키 없는 RainViewer, USGS, GDACS부터 실제 좌표와 토글을 복구한다.
3. OpenSky, AISStream, FIRMS, TomTom은 서버 프록시·쿼터·캐시를 붙여 복구한다.
4. 실제 Supabase 프로젝트 연결 뒤 회원가입·로그인·세션을 검증한다.
5. PC 기능 안정화 후 모바일 전용 배치를 별도 패스로 진행한다.
