# Earth Radar 세로 유튜브 쇼츠 런칭 플랜

## 한 줄 콘셉트
손짓과 한국어 음성으로 지구를 움직이고, 공개 지도 데이터 위에 항공기, 위성, 차량, 사람 흐름, CCTV 시야각을 겹쳐 보는 미래형 3D 상황판.

## 35초 쇼츠 구성
1. 0-3초: 깨진 일반 지도 화면 대신 어두운 지구 HUD가 켜지는 장면.
   - 자막: "구글 어스처럼 보이는데, 손으로 움직입니다."
2. 3-8초: 서울 상공으로 빠르게 줌인.
   - 자막: "한국어로 말하면 지도가 움직임"
   - 음성 예시: "서울 남산으로 이동해."
3. 8-14초: 사람/차량 레이어를 켜고 점들이 나타나는 장면.
   - 자막: "실제 개인 추적 아님. 공개 데이터 + 안전한 시각화."
4. 14-20초: 위성 레이어와 항공/교통 레이어를 겹치는 장면.
   - 자막: "위성, 차량, 재난 레이어를 한 화면에."
5. 20-26초: 손 추적 패널을 켜고 손으로 지구를 돌리는 장면.
   - 자막: "마우스 없이 손으로 회전/확대."
6. 26-31초: 거리 사진 버튼을 눌러 공개 거리 사진 뷰로 넘어가는 장면.
   - 자막: "스트리트뷰 대체: 공개 거리 사진."
7. 31-35초: 도메인과 베타 모집 콜투액션.
   - 자막: "베타 준비 중: earthradar.app"

## 플랜 구조
플랜 나누기는 오래전부터 검증된 수익화 방식입니다. 우리가 매일 쓰는 앱과 AI 서비스도 대부분 무료 체험, 개인 유료, 고급 멤버십을 나눕니다. Earth Radar도 기능을 그냥 막는 구조가 아니라, 사용자가 커질수록 더 안정적인 지도, 연결, 공개 범위를 얻게 만드는 구조로 갑니다.

### FREE
- 오프라인 지도: 불가
- 핸드폰과 컴퓨터 연결: 불가
- 베타 테스트 공식 참여: 불가
- 오픈소스 공개: 안 함
- 장점: 온라인 지도, 기본 HUD, 한국어 화면, 거리 사진 버튼, 기본 데이터 레이어는 잘 작동
- 약점: 인터넷이 끊기면 지도 품질과 실시간 레이어가 제한됨

### PRO
- 오프라인 지도: 가능하지만 지연 있음
- 핸드폰과 컴퓨터 연결: 가능하지만 일부 기능 제한
- 오픈소스 공개: 일부 공개
- 장점: 개인/소규모 팀이 실제로 쓰기 좋은 플랜
- 약점: 완전한 실시간 동기화, 고급 베타, 전체 소스 공개는 MAX 크루로 제한

### MAX 크루
- 이름: MAX가 아니라 "MAX 크루"
- 오프라인 지도: 지연 없음
- 핸드폰과 컴퓨터 연결: 아주 잘됨
- 오픈소스 공개: 풀 공개
- 베타/테스트: MAX 크루에 선공개
- 구독료: 별도
- 장점: 제품을 같이 키우는 핵심 멤버십
- 약점: 가격이 높고, 고급 기능이 많아 초보자에게는 과할 수 있음

## 오프라인 전략
- FREE는 오프라인을 제공하지 않고 온라인 지도 품질에 집중합니다.
- PRO는 도시 단위 캐시를 제공하되, 로딩 지연이 있다는 점을 명확히 안내합니다.
- MAX 크루는 미리 내려받은 지도 타일, 건물 캐시, 장면 프리셋을 제공해 지연 없이 보이게 합니다.
- 기본 제품 화면은 디테일을 살리기 위해 NASA/Esri/Google 가능 경로를 우선하고, 오프라인은 품질 낮은 기본값이 아니라 유료 기능으로 분리합니다.

## 필요한 키
- 화염/산불: `FIRMS_MAP_KEY`
- 실사 3D 지구: `GOOGLE_MAPS_API_KEY` 또는 `CESIUM_ION_TOKEN`
- 실시간 교통: `TOMTOM_API_KEY`
- 선박: `AISSTREAM_API_KEY`
- 음성 고급 모드: `OPENAI_API_KEY`

## 촬영 컷 리스트
- 서울 상공 NASA/Esri 위성사진 줌인
- 뉴욕으로 이동하는 장면
- 위성 레이어 켜기
- 사람·차량 활동 레이어 켜기
- 온도 레이어 켜기
- CCTV 패널과 시야각 느낌
- 손 추적 켜기 전/후 비교
- 거리 사진 버튼 클릭
- 전체 지구로 줌아웃
- 모바일 PWA 홈 화면 설치 장면

## 차별점
- 한국어 음성 명령과 손 추적을 지도 인터페이스에 결합
- 위험한 감시/해킹이 아니라 공개 데이터와 안전한 시뮬레이션 중심
- Google 3D 키가 없어도 NASA/Esri/OSM/Mapillary 조합으로 데모 가능
- 기관용 상황판, 교육용, 전시용, 쇼츠 콘텐츠까지 같은 앱으로 재사용

## 수익화
- 무료 공개 데모: 조회수와 베타 대기자 확보
- Pro 구독: 고급 레이어, 저장된 장면, 팀 공유
- 기관 납품: 지자체/학교/전시/스마트시티용 커스텀 대시보드
- 영상 템플릿 판매: 쇼츠/릴스용 장면 프리셋 패키지
