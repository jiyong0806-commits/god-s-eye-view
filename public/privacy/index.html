PLASMA 계정

계정 데이터 안내

개발 중인 GOD'S EYE VIEW와 God Flow는 하나의 Supabase 프로젝트에서 PLASMA 계정을 관리합니다. 각 사이트와 데스크톱 앱에서는 별도의 로그인 세션을 사용할 수 있습니다.

저장되는 정보

회원가입 시 이메일, 인증 정보, 표시 이름이 계정 서버에 저장됩니다. 비밀번호 처리는 Supabase Auth가 담당하며 앱은 평문 비밀번호를 저장하지 않습니다. 로그인 유지를 위한 세션은 이 기기의 브라우저 저장소에 보관됩니다.

맞춤 뉴스에 동의한 경우에만 계정 설정에서 입력한 직업, 취미, 관심어, 지역, 연령대가 프로필에 저장됩니다. 맞춤 동의를 끄고 저장하면 해당 선택 정보는 비워집니다. 저장한 장소와 God Flow 작업은 계정별 접근 정책으로 관리합니다.

외부 연결

장소 검색어와 지도 조회 지역은 검색·지도 공급자에게 전달될 수 있습니다. 뉴스 관심어 비교는 이 기기에서 처리하며 개인정보를 뉴스 공급자나 생성형 AI에 전송하지 않습니다. 마이크 권한은 음성 기능 사용 시 별도로 요청합니다.

개발 상태

계정 전체 삭제와 운영자 문의 창구는 아직 완성되지 않았습니다. 민감정보를 입력하지 마세요. 이 문서는 현재 구현의 데이터 처리 안내이며 상용 운영에 필요한 정책 검토가 완료됐다는 의미는 아닙니다.
